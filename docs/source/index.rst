tinyecs-compsys - compsys namespace package for tinyecs
=======================================================

This is the top level namespace package for ``tinyecs`` package.  This package
itself only imports modules and provides a unified component ID enum.  To see
details about individual components and systems, please look at the
documentation of the official sub-packages:

* `tinyecs.compsys.base`_
* `tinyecs.compsys.dynamics`_
* `tinyecs.compsys.sdl2`_
* `tinyecs.compsys.patternengine`_

.. _tinyecs.compsys.sdl2`: https://tinyecs-compsys-sdl2.readthedocs.io/en/latest/
