tinyecs-compsys - compsys namespace package for tinyecs
=======================================================

.. toctree::
   :caption: Contents:

This is the top level namespace package for ``tinyecs`` package.  This package
itself only imports modules and provides a unified component ID enum.  To see
details about individual components and systems, please look at the
documentation of the official sub-packages:

* [``tinyecs.compsys.base``](https://tinyecs-compsys-base.readthedocs.io/en/latest/)
* [``tinyecs.compsys.dynamics``](https://tinyecs-compsys-dynamics.readthedocs.io/en/latest/)
* [``tinyecs.compsys.sdl2``](https://tinyecs-compsys-sdl2.readthedocs.io/en/latest/)
* [``tinyecs.compsys.patternengine``](https://tinyecs-compsys-patternengine.readthedocs.io/en/latest/)
